# Simple Interest Calculator

## Description
This project is a simple interest calculator that calculates the interest earned on a principal amount over a specified period of time at a given annual interest rate.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Inputs
- **Principal:** The initial amount of money.
- **Rate:** The annual interest rate (percentage).
- **Time:** The duration in years.

## Example
- Principal: 1000
- Rate: 5%
- Time: 2 years

Calculation:

Simple Interest = (1000 × 5 × 2) / 100

**Simple Interest = 100**

## Output
The simple interest earned is 100.
